# 릴스 고정 진행자 기준 이미지 만들기

모든 릴스에 같은 사람이 나오게 하려고, 한 번만 진행자 기준 이미지를 만들어 `assets/reel_host/` 에 넣어 둡니다.
파일이 있으면 Actions 가 매 회차 텔레그램으로 같이 보내 주고, Flow 에서 영상을 만들 때 '재료(Ingredients)'로 넣으면 됩니다.

## 1. 현재 기준 이미지(2026-11-21 교체)

- `assets/reel_host/host_1_main.jpg` : 정면 상반신 대표 이미지(실험실 배경, 손으로 가리키는 자세)
- `assets/reel_host/host_2_sheet_front_side_back.jpg` : 정면·측면·뒷모습 캐릭터 시트(전신, 흰 배경)
- 외모: 30대 초반 한국인 여성, 가운데 가르마의 긴 흑갈색 머리를 낮게 묶은 포니테일(앞머리 없음, 얼굴 옆 잔머리 몇 가닥), 얇은 은색 둥근 안경, 무릎 길이 흰 가운(앞을 연 채) + 네이비 단추 셔츠 + 네이비 일자 바지 + 흰 밑창 네이비 스니커즈.
- 액세서리 없음(헤드셋·마이크·모자·장신구·명찰·펜 등 추가 금지).
- Flow 에서는 두 장을 모두 참고 이미지(재료)로 넣는다. 캐릭터 시트가 측면·뒷모습 컷에서도 머리·옷이 바뀌지 않게 잡아 준다.

## 2. 저장소에 넣기

- 이미지를 `assets/reel_host/` 에 저장해 main 에 올립니다(이름순으로 최대 3장까지 전송됨).
- 진행자 외모를 바꾸고 싶으면 이 이미지와 ROUTINE_PROMPT.md step3 7번의 HOST 문단을 함께 바꿉니다(둘이 다르면 인물이 흔들립니다).
